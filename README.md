# Loomwall · LOOW

> 这是用大肥鱼制作的一个开源的 Android 动态壁纸引擎与编辑器。把图层、规则、数据织成一张会动的壁纸。

在浏览器里完成整张动态壁纸的设计：搭版面、连逻辑、打关键帧、绑定系统数据，
然后一键推送到手机，立刻在桌面上看到效果。渲染引擎、编辑器、场景格式全部自研，
不引入任何第三方 SDK。

## 特性

- **自研 OpenGL ES 2.0 渲染**：单渲染线程，静止时 0 帧，不空转不耗电
- **浏览器编辑器**：版面、图层、属性、动画、触发器集中在一处，改完即可推送
- **节点式触发器**：手势、命中图层、定时、出现时、变量变化，拖线即成逻辑
- **关键帧时间轴**：多组动画、六种缓动、中途可打断的补间
- **数据绑定**：电量、温度、内存、存储、时间、通知、网络 → 直接驱动图层属性
- **倾斜视差**：分层位移、每层独立景深，30Hz 节流 + 死区过滤
- **零第三方依赖**：场景解析用平台自带 `org.json`

## 技术栈

Kotlin · OpenGL ES 2.0 · `WallpaperService` · 原生 Web 编辑器（无前端框架）

## 状态
