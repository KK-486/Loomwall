# 网页版预设编辑器

在电脑浏览器里编辑壁纸预设，导出的就是手机端渲染器直接读取的那套 JSON。

## 打开方式

直接双击 `index.html`（不需要服务器、不需要联网、不需要安装任何东西）。

- 推荐浏览器：Chrome / Edge
- 如果浏览器拦了本地文件，可以在本目录执行 `python -m http.server 8080`，然后访问 <http://127.0.0.1:8080>

## 能做什么

| 区域 | 能力 |
|---|---|
| 左栏 | 图层（矩形）列表、动画列表；增删 |
| 中间 | 真实比例（9:19.5）预览；点选矩形、拖动移动、四角拖动改尺寸 |
| 右栏 | 位置 / 尺寸 / 旋转 / 缩放 / 透明度 / 颜色 / 背景色 / 元素 id |
| 底部时间轴 | 播放头（点击或拖动定位）、关键帧菱形（可拖动改时间）、插入 / 删除帧、缓动选择与曲线预览、触发方式、循环、时长、播放预览 |
| 导入导出 | 读入预设包 / 单个 JSON；导出单文件包或 3 个标准 JSON |

## 格式约定（与手机端完全一致）

- 坐标：`x / y / width / height` 都是**画布宽度的百分比**，原点左上角，y 向下
- 颜色：`#AARRGGBB`
- 关键帧：`t` 归一化 0..1、严格递增；**末帧可以早于 1**，之后保持末值
- 触发：`always`（常驻，壁纸可见即播）/ `tap`（点击）

导出的三个文件与手机端 `PresetStore` 读取的完全对应：

```
manifest.json      # formatVersion(包版本 0.2) / engineMinVersion / name / author / license
scene.json         # formatVersion(0.1) + root 容器 + rect 列表
interactions.json  # formatVersion(0.1) + animations
```

单文件包则是 `{ manifest, scene, interactions }` 三合一，便于分享。

## 当前限制

- 只支持矩形元素（与手机端 v0.1 场景格式一致）
- 不支持图片 / 文本 / 嵌套容器
- 导出前会自动校验；有错误时拒绝导出并列在右栏「校验」里
